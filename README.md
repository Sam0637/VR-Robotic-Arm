# **VR Robotic Arm**



**Members:** Quentin COURTOIS, Jules GIRARDON, Samira KAIDI

**Coordination platforms:**	GitHub repository + Teams





* **Overview:**

This project is a virtual reality experience in which the user controls a 6-axis robotic arm simply by moving their hands, with no controller or joystick. Immersed in a virtual workshop, the user stands in front of the robot, moves a hand, and the arm follows in real time. A simple gesture, such as a pinch, opens and closes the gripper so the user can pick up, move and place objects in the scene.

Concept and Motivation

Operating an industrial robotic arm normally requires specialized interfaces, training and access to expensive hardware. Virtual reality makes this accessible: users can learn how a robotic arm moves and experiment safely, with natural gestures and no risk of damaging equipment. The project explores human-robot interaction in an immersive and intuitive way, with applications in education, training and teleoperation.



* **How It Works:**



1. Hand input. The user's hands are tracked in the virtual environment and used as the control input.
2. Arm control. The hand position is translated into a target for the robot, and the arm's joints move to follow it smoothly and realistically.
3. Interaction. Gestures trigger actions such as grasping and releasing objects.
4. Virtual environment. A scene with the robot and interactive objects gives the user clear tasks.



* **Objectives and Deliverables:**



1. A playable VR scene featuring a 6-axis robotic arm that responds to the user's hands in real time.
2. Smooth, stable and intuitive control of the arm.
3. At least one grab-and-move interaction with objects in the scene.
4. A documented GitHub repository and an organized project management page.



* **Possible Extensions**

Pick-and-place challenges with a score, visual feedback on the arm's joints, and additional gestures or interactions.
